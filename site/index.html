The app

Real windows from Keyware 1.4.3.

Text mode

Describe the shortcut in a normal sentence.

Switch the Quick Binder to Text, write what the key should do, and press Generate. You review the proposal and press Save. Nothing is saved until you do.

  • Works in every window unless you name an app.
  • Shells, scripts, and non-web links are refused.
  • Free daily limit, or your own Gemini or Groq key.

Profiles

Different shortcuts for each app.

Global works everywhere. Gaming, Browser, and Code turn on when that window is in front. A per-app rule can let the app keep its own shortcut, run Keyware's action, or both.

Macros

Keys, clicks, and waits, in order.

A macro is a list of steps. Delays are exact. Keys get a small human jitter. Panic cancels a running macro between steps.

1.4.1

Scripting is optional.

Turn on Advanced scripting in Settings when you want a script box. Leave it empty and the action runs as usual. do runs that action.

  • The keyboard hook never runs a script.
  • No shells, no commands, no wait over 2 seconds.
  • Pause and Ctrl+Alt+Shift+Esc stop it between steps.

Safety

An update check, a pause, and a panic stop.

Once a day Keyware can ask GitHub which release is current. It does not download the file. Ctrl+Alt+F12 pauses. Ctrl+Alt+Shift+Esc releases the hook and every key it was holding.

Also included

The keys people actually rebind.

Remap the Copilot key

Keyware sees the Copilot key as one key. Bind it to an app, a shortcut, a macro, or tap for one thing and hold for another. Windows 11 can also do less, under Settings › Bluetooth & devices › Keyboard › Customize Copilot key.

Caps Lock, your way

Tap Caps Lock for Esc, hold it for Ctrl, or turn it off. Shift Caps Lock still toggles capitals.

Tap, hold, and chords

A short tap and a long hold can do different things. Double-tap, triple-tap, and modifier chords work too. A leader key such as F13 then a follow-up covers macropads that send F13 to F24.

Auto-click

Left, right, or middle button, from 1 to 50 clicks a second, while a key is held or as a toggle. It always stops on pause, panic, or when Keyware turns off.

Conflicts are refused

One trigger can't do two things. If it is already used, Keyware says so and offers to replace that binding.

Setups inside a profile

Up to 9 numbered setups, each with its own keys. Hold the number for 8 seconds to switch. A quick tap still types the number.

Trust

What it does, and what it will not do.

Unbound keys pass through

Keyware only acts on keys you've bound. Everything else reaches Windows untouched.

Panic chord

Ctrl Alt Shift Esc drops the hook immediately and releases every key.

No admin rights

It runs as a normal app and does not inject keys into elevated windows.

Settings stay on the PC

Bindings live in %APPDATA%\Keyware\config.json. The hook engine does not go online. Text mode sends the sentence you typed, not your keystrokes. Privacy statement

FAQ

Questions, answered.

More in the full guide, including troubleshooting.

Is it free?

Yes. Keyware is free and open source under the MIT license: no trial, no paid tier, no ads, and no account. Text mode and scripting are included.

Is it safe?

Keyware runs as a normal app without admin rights and has no ads or tracking. Your bindings are stored locally in %APPDATA%\Keyware\config.json. Keys you haven't bound pass straight through to Windows, and Ctrl Alt Shift Esc switches everything off instantly.

The key engine does not record or upload what you type. Text mode sends the sentence you typed, plus a short summary of your existing triggers and profile names, so the AI can draft a binding for you to review. A Play action looks up the song or video name you entered. Feedback sends the note you write, the email you enter, the app version, and a random install ID; the server keeps only a short salted hash of that ID. Details are in the privacy statement.

Keyware isn't code-signed, so Windows SmartScreen may warn you. Click More info → Run anyway. The SHA-256 for each file is listed with the download.

What is Advanced scripting?

A switch in Settings. Off, and you never see it. On, a binding can carry a short script that branches on the app, profile, setup, or held modifiers, then types, clicks, opens something, or runs the normal action with do. It cannot open a shell, run a command, or wait more than 2 seconds. The keyboard hook never runs it. Pause and Ctrl Alt Shift Esc stop it between steps. How scripts work

Is there a limit on Text mode?

Text mode works straight away with Keyware's free AI, which has a fair daily limit of 20 requests per PC. If you hit it, you'll see “Daily AI limit reached, try tomorrow or add your own free key”, and Manual mode keeps working as normal.

Want more? Add your own free Google Gemini or Groq key in Settings and Text mode has no Keyware limit at all. It takes about a minute: see Use your own AI key.

Does it work in games?

Yes, in most games. The Gaming profile switches on automatically when your game is in front, and auto-click, holds, and macros all work there.

Two things to know: if a game runs as administrator, Windows won't let a normal app send it keys, so Keyware's remaps pass through instead. And some competitive online games with strict anti-cheat ban macros or auto-clickers, so check a game's rules before using them there. Ctrl Alt F12 pauses Keyware at any time.

How do I uninstall it?

There's no installer. To remove Keyware:

  1. In Settings, turn off Start Keyware with Windows. It is on by default. Turning it off deletes the Keyware startup entry for your Windows account. If you skip this, Windows still tries to open Keyware when you sign in.
  2. Right-click the Keyware icon in the system tray and choose Quit.
  3. Delete Keyware.exe. If you also downloaded the ARM64 build, delete Keyware-arm64.exe too.
  4. Optional: press Win R, type %APPDATA%\Keyware and delete that folder. That removes your settings, the install ID, and a saved AI key. They stay on the PC until you do.
Can it remap the Copilot key?

Yes. Record it in the Quick binder (it shows as Copilot key) and bind it to anything, including tap for one thing and hold for another. While it's bound, Copilot or Search won't open.

If you only want it to open Search, Copilot, or one app, Windows 11 can do that without any extra software: Settings › Bluetooth & devices › Keyboard › Customize Copilot key. Newer Windows 11 updates add Right Ctrl and the Context menu key as choices. See the guide for details.

Which versions of Windows are supported?

Windows 10 and Windows 11. This page has two downloads: 64-bit (x64) Keyware.exe for most PCs, and native ARM64 Keyware-arm64.exe for Windows on ARM, including Copilot+ PCs. On ARM64 Windows the 64-bit file runs under emulation. Each button lists that file's size and SHA-256.

Does Keyware work on a Mac?

No. There is no Mac download, on Apple Silicon or Intel. Keyware remaps keys with a Windows keyboard and mouse hook. On a Mac this program can edit a config, but turning it on does not remap keys. A working Mac version would be a different input system, not another build of Keyware.exe.
