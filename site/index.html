Features

Every key can do more.

Pick a trigger, pick an action, press Save. Keyware handles the timing, the conflicts and the switching.

New in 1.3.7: setups

Give a profile up to 9 numbered setups, like 1 Elytra and 2 Spear in Minecraft, each with its own keys. Hold the number key for 8 seconds to switch. A quick tap still types the number. See what's new

One-key on/off

Ctrl Alt F12 turns Keyware off and on, with a small note each time. Pick your own shortcut in Settings.

Per-app shortcut rules

Let one app keep its own shortcut, run Keyware's action, or both. Just say it in Text mode: "Ctrl+K opens Notion, but not in Cursor". Version 1.3.8 passes both the key press and the key release, so App or Both no longer leaves a stuck key.

Chords & key combos

Map any modifier combo to an action. Ctrl Win Shift R opens YouTube; a single key can fire a whole combo like Ctrl Shift T.

CtrlWinShiftR

Tap, hold, double & triple-tap

One key, several jobs. Give any key a tap action and a separate hold action (200 ms by default, you pick the time), or double- and triple-tap for more. Keys without a hold action are never delayed.

Caps Lock, your way

Tap Caps Lock for Esc, hold it for Ctrl, bind it to anything, or turn it off. Shift Caps Lock still toggles capitals, and it never gets stuck on.

Remap the Copilot key

Keyware sees the Copilot key as one key, so it can open any app, send a shortcut, run a macro, act as Ctrl while held, or do different things in different apps. Windows 11 also has a simpler built-in option in Settings › Bluetooth & devices › Keyboard › Customize Copilot key (Search, Copilot or an app, and on newer updates Right Ctrl or the Context menu key). Keyware is for when you want more than that.

Leader-key sequences

Tap a leader such as F13, then a follow-up key within 1.5 s. Dozens of shortcuts, zero finger gymnastics. Macropads and stream decks that send F13 to F24 work too.

Macros

Chain keys, typed text, mouse clicks and exact waits into one step-by-step macro. Panic cancels it between steps.

  1. Key Ctrl + L
  2. Text github.com
  3. Wait 150 ms
  4. Key Enter

Open anything, type anything

Open a URL, launch an app, type a snippet like your email address, or send a key combo. All from a single keypress.

Auto-click

Left, right or middle button at 1 to 50 clicks per second. Run it while you hold a key, or toggle it on and off.

20 CPSToggle

Per-app profiles

Global, Gaming, Browser and Code profiles switch on their own when the active window changes.

Conflict prevention

One key can't do two things. If a trigger is already taken, Keyware tells you and offers to replace it.

Pause & dry run

Ctrl Alt F12 pauses everything instantly. Dry-run mode logs what would fire and lets every key through.

Lightweight and private

A single small app that sits in your tray. No ads, no tracking, no account and no admin rights. Your settings stay on your PC in a plain JSON file.

Text mode

Just say what
the key should do.

Switch the Quick Binder to Text, describe a shortcut in plain English, and press Generate. AI fills in the trigger, the action and the details for you.

  • 1Type “F2 opens YouTube and searches minecraft”.
  • 2Review the proposed binding. Tweak it in Manual if you like.
  • 3Press Save. Nothing is ever saved automatically.

Unsafe requests such as shell commands, scripts or non-web links are rejected, and clashes get the normal conflict check.

FAQ

Questions, answered.

More in the full guide, including troubleshooting.

Is it free?

Yes. Keyware is completely free: no trial, no paid tier, no ads and no account. Every feature on this page, including Text mode, is included.

Is it safe?

Keyware runs as a normal app without admin rights and has no ads or tracking. Your bindings are stored locally in %APPDATA%\Keyware\config.json. Keys you haven't bound pass straight through to Windows, and Ctrl Alt Shift Esc switches everything off instantly.

The key engine does not record or upload what you type. Text mode sends the sentence you typed (plus a short summary of your existing triggers and profile names) so the AI can draft a binding for you to review. A Play action looks up the song or video name you entered. Feedback sends the note you write, the email you enter, the app version and a random install ID; the server keeps only a short salted hash of that ID. Details are in the privacy statement.

Keyware isn't code-signed, so Windows SmartScreen may warn you when you open a new download. Click More info → Run anyway. The SHA-256 for this file is listed with the download.

Is there a limit on Text mode?

Text mode works straight away with Keyware's free AI, which has a fair daily limit of 20 requests per PC. If you hit it, you'll see “Daily AI limit reached, try tomorrow or add your own free key”, and Manual mode keeps working as normal.

Want more? Add your own free Google Gemini or Groq key in Settings and Text mode has no Keyware limit at all. It takes about a minute: see Use your own AI key.

Does it work in games?

Yes, in most games. The Gaming profile switches on automatically when your game is in front, and auto-click, holds and macros all work there.

Two things to know: if a game runs as administrator, Windows won't let a normal app send it keys, so Keyware's remaps pass through instead. And some competitive online games with strict anti-cheat ban macros or auto-clickers, so check a game's rules before using them there. Ctrl Alt F12 pauses Keyware at any time.

How do I uninstall it?

There's no installer. To remove Keyware:

  1. In Settings, turn off Start Keyware with Windows. It is on by default. Turning it off deletes the Keyware startup entry for your Windows account. If you skip this, Windows still tries to open Keyware when you sign in.
  2. Right-click the Keyware icon in the system tray and choose Quit.
  3. Delete Keyware.exe. If you also downloaded the ARM64 build, delete Keyware-arm64.exe too.
  4. Optional: press Win R, type %APPDATA%\Keyware and delete that folder. That removes your settings, the install ID and a saved AI key. They stay on the PC until you do.
Can it remap the Copilot key?

Yes. Record it in the Quick binder (it shows as Copilot key) and bind it to anything, including tap for one thing and hold for another. While it's bound, Copilot or Search won't open.

If you only want it to open Search, Copilot or one app, Windows 11 can do that without any extra software: Settings › Bluetooth & devices › Keyboard › Customize Copilot key. Newer Windows 11 updates add Right Ctrl and the Context menu key as choices. See the guide for details.

Which versions of Windows are supported?

Windows 10 and Windows 11. This page has two downloads: 64-bit (x64) Keyware.exe for most PCs, and native ARM64 Keyware-arm64.exe for Windows on ARM, including Copilot+ PCs. On ARM64 Windows the 64-bit file runs under emulation. Each button lists that file's size and SHA-256.

Does Keyware work on a Mac?

No. There is no Mac download, on Apple Silicon or Intel. Keyware remaps keys with a Windows keyboard and mouse hook. On a Mac this program can edit a config, but turning it on does not remap keys. A working Mac version would be a different input system, not another build of Keyware.exe.
