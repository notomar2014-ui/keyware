01

Getting started

Keyware is a single program file. There's no installer and nothing to sign up for.

  1. Download

    Most PCs: Download 64-bit (x64) and save Keyware.exe (v1.4.1, 20.8 MB). SHA-256 6EE816FD5706AD91FF13F1C6FA97E6EDA4E9738E884C7D10AD08BBE0A21554A0. Windows on ARM, including Copilot+ PCs: Download ARM64 and save Keyware-arm64.exe (v1.4.1, 16.1 MB). SHA-256 D9CEEE6E7AC046E38FC0E736339E011D07175B191E874CCFDAF1DAA460E75E8D. On ARM64 Windows the 64-bit file runs under emulation. Put the file somewhere you'll find it again, such as your Desktop or a Tools folder. Keyware runs on Windows 10 and 11. There is no Mac download. On a Mac, turning Keyware on does not remap keys.

  2. First launch: “Windows protected your PC”

    Keyware isn't code-signed, so Microsoft Defender SmartScreen may show a blue warning when you open a new copy. Click More info, then Run anyway. A different download, such as a new version or the ARM64 file, can show the prompt again. Compare the SHA-256 on the download with Get-FileHash .\Keyware.exe -Algorithm SHA256 if you want to confirm the file.

  3. Turn it on

    The window opens with a few sample bindings so you can see how things look. Keyware stays off until you switch it on: click the status dot next to the KEYWARE title (green means on), or save a binding, which turns Keyware on automatically.

The Keyware window

  1. 1
    Status dot. Green when Keyware is on. Click to toggle.
  2. 2
    Profiles. Global, Gaming, Browser, Code and any you add. Select one to see its bindings.
  3. 3
    Bindings. Every shortcut in the selected profile, with a switch to enable or disable it, plus Edit, Run and delete.
  4. 4
    Quick binder. Text asks “What should this key do?”. Write a normal sentence. Manual is the field-by-field editor.
  5. 5
    Log. What Keyware did and why. Hide it with Hide log. It's also saved to %APPDATA%\Keyware\keyware.log.
  6. 6
    Settings gear. Opens Settings: sounds, Dry run, Start with Windows, the leader key, your own AI key and feedback. Back returns to your bindings.

The tray icon

Closing the window doesn't quit Keyware. It keeps running in the system tray (the area by the clock; click the ^ arrow if you don't see the keyboard icon). Right-click the icon for:

  • Show KeywareOpen the window again
  • Turn ON / Turn OFFThe master switch
  • PauseSame as Ctrl + Alt + F12
  • Reload configRe-read your settings file
  • Open configOpen config.json in your editor
  • QuitExit Keyware completely

Dimmed icon with a red dot: Keyware is off.

Pause mark: Keyware is paused. Press Ctrl Alt F12 again to resume.

Closing the window (the X) hides Keyware to the tray, and your keys keep working. Only Quit exits it.

Start with Windows is on by default: Keyware starts quietly in the tray when you sign in, without opening the window. Your hotkeys work right away. Turn it off any time in Settings with Start Keyware with Windows. Closing the window keeps Keyware running in the tray; Quit in the tray fully closes it.

Triggers: how a key fires

Every binding has a trigger. Pick one in the Quick binder's trigger dropdown.

TriggerHow it worksExample
TapA quick press runs the action. The key itself isn't typed.F2 opens YouTube
HoldHold the key for a set time (300 ms to 10 s). A short press still types the key normally, or does a separate Tap action if you pick one.Hold P 2 s opens Spotify
Double-tapTwo taps within 250 ms. A single tap still types the key after a short pause.F8 F8 starts auto-click
Triple-tapThree taps within 250 ms.Q Q Q types a sign-off
ChordModifiers (Ctrl, Alt, Shift, Win) plus one key, pressed together.Ctrl Win Shift R
LeaderTap the leader key, then this key within 1.5 s. F13 makes a safe leader because it doesn't type anything.F13 → Y

Tip. Tap, Hold and multi-tap only apply when no modifier is held, so Ctrl P still prints even if you've bound Hold P. Turn on Audio ticks at hold tiers in Settings to hear when a hold has lasted long enough.

Any key or mouse button (new in 1.3.6)

A trigger can be almost anything you can press: every Windows key, the mouse wheel (up or down, also with a modifier like Ctrl + wheel), wheel tilt left and right, and extra mouse buttons (X1 to X16). Click Record in the Quick binder and press the button. Keys Keyware has no name for still work and show up as a code such as vk_XX or sc_XXX.

Tap vs hold: two jobs on one key

Pick the Hold trigger, choose what holding does, then pick what a quick tap does under Tap. The tap can type the key as normal, do nothing, send another key or shortcut, open a URL or app, or type text.

  • Time. With a Tap action the hold starts from 100 ms (200 ms is a good default). Press longer than that and it counts as a hold.
  • Keep the keys held. When the hold action is a key combo such as Ctrl, tick Keep the keys down while I hold and the key acts as Ctrl for as long as you hold it, so Caps Lock + C copies. Pressing another key while it's down counts as a hold straight away, so fast typing works.
  • No lag anywhere else. Only keys that have a hold action wait to see if you're tapping or holding. Every other key types instantly.

In Text mode you can just say it: “tap caps lock for escape, hold it for ctrl”.

The Copilot key and Caps Lock

Copilot key

Many new laptops have a Copilot key where Right Ctrl used to be. Inside, it presses Win Shift F23 all at once, which is why most remappers can't bind it on its own. Keyware recognises that burst as one key called Copilot key:

  1. Press Capture in the Quick binder and press the Copilot key. It records as Copilot key.
  2. Pick any action, or use the Hold trigger for separate tap and hold actions.
  3. Save. While the binding is on, Copilot or Search no longer opens, and Win and Shift don't leak or stick. Other Win Shift shortcuts, like Win Shift S, keep working.

Built into Windows. If you only want it to open Search, Copilot or one app, you don't need Keyware: go to Settings › Bluetooth & devices › Keyboard › Customize Copilot key. Newer Windows 11 updates also offer Right Ctrl and the Context menu key there. Set it back to the default if you'd rather Keyware handle the key, because Windows' choice runs first.

Good to know: a few keyboards send the Copilot key differently, and it may not be recognised there. Keyware can't see it in windows running as administrator, and if the binding is off or paused the key does what Windows normally does.

Caps Lock

Bind Caps Lock like any other key: tap for Esc and hold for Ctrl, open an app, or choose Do nothing to turn it off. While it's bound, pressing it doesn't switch on capitals, and if the Caps Lock light was on when you bound it, Keyware turns it off once. Shift Caps Lock still toggles capitals when you need them.

Macropads and stream decks

Macropads and stream decks are great with Keyware because their buttons can send keys no normal keyboard has, so they never clash with your typing.

  1. Set the pad to send F13 to F24. In the pad's own software (VIA, QMK, or the maker's app), give each button a keyboard key from F13 to F24. For more buttons, use Ctrl F13, Alt F13 and so on.
  2. Record the button in Keyware. Press Capture and press the pad button. It records as F13, F14 and so on.
  3. Bind it per app. Make a profile for each app and give the same button a different job in each one.
AppExample button bindings
OBSF13 start or stop recording, F14 switch scene
PhotoshopF13 brush, F14 undo, hold F15 for the hand tool
Premiere ProF13 razor, F14 ripple delete, F15 export
FigmaF13 frame, F14 component

Stream deck apps that can send a hotkey work the same way: set the button to send F13 to F24 and bind it in Keyware. Text mode knows these apps too: “F13 in OBS starts recording”.

03 · Organize your keys

Organize your keys with Profiles

A profile is a group of bindings for one part of your day: Gaming, School, Coding, whatever you need. The same key can do something different in each one, and Keyware switches between them on its own when you change windows.

  1. 1
    Your profiles. Click one to see and edit its bindings. The highlighted profile is the one you're editing.
  2. 2
    + Profile adds a new group. Edit live profile jumps to whichever profile is active right now.
  3. 3
    Name and apps. The profile's name and the programs that switch it on. Global says “Every other window”.

The built-in profiles

  • Global works in every window. Put shortcuts you want everywhere here.
  • Gaming switches on when a game is in front. Out of the box it covers Minecraft (javaw.exe, minecraft.exe); add your own games' .exe names. Called “Minecraft” in earlier versions. It's renamed to Gaming automatically when you update.
  • Browser for Chrome, Edge, Firefox and friends.
  • Code for your editor, such as VS Code (Code.exe).

How switching works

chrome.exe→Browser
javaw.exe→Gaming
Code.exe→Code
anything else→Global

Keyware checks the window in front about twice a second. App profiles add to Global, so your everyday shortcuts keep working. If an app profile uses the same trigger as a Global binding, the app's version wins while that app is in front, and Keyware shows a short note when you save.

Make your own, e.g. a School profile

  1. Click + Profile and name it School.
  2. In the apps field, list the programs it's for, for example WINWORD.EXE, ONENOTE.EXE or Teams.exe. (Task Manager → Details shows a program's exact name.)
  3. Leave Enabled on and press Save. With School selected, add its bindings in the Quick binder.

Turn a whole profile off with its Enabled switch, for example during exams or a tournament, without deleting anything.

04

Manual mode

Manual is the Quick binder's default view. You choose every field yourself.

  1. Pick the profile on the left that the binding belongs to.
  2. Optional: type a Label such as “Open YouTube”.
  3. Click Click here, then press the keys (or Capture) and press the key or combo you want. You can also type it, like Ctrl + Shift + R.
  4. Choose the trigger: Tap, Hold, Double-tap, Triple-tap, Chord or Leader.
  5. Choose the action and fill in its details.
  6. Press Save binding. It works straight away.

To change a binding later, press Edit on its card; to try it without pressing the keys, press Run.

05

Text mode (AI)

Switch the Quick binder to Text. The box is labeled What should this key do?. Write a normal sentence, such as F2 opens YouTube or F7 opens Calculator. There is no special format to learn.

If you do not name an app, the shortcut works in every window. The proposed card says Every window. If you say in Chrome or while gaming, it says Only while that app is in front.

  1. Type something like “F2 opens YouTube and searches minecraft”.
  2. Press Generate (or Ctrl Enter). A Proposed binding card shows the trigger, the action and where it works. Check that line before you save.
  3. Happy? Press Save binding. Want to tweak it? Press Edit in Manual. Nothing is saved until you press Save.

One description, several bindings

You can ask for up to 8 bindings in one go. Keyware proposes each one separately so you can review them all before saving.

“F9 opens YouTube, F10 types my email, and F8 auto-clicks 15 times a second while I hold it”

  • F9 Tap → Open URL youtube.com
  • F10 Tap → Type text you@example.com
  • F8 Hold → Auto-click left, 15 per second

When it says no

Text mode only makes key bindings. If you type something unrelated, like “write me a poem” or “what's the weather”, you'll see:

That doesn't look like a key binding. Describe what you want your keys to do, like “F9 opens YouTube”.

For your safety it also refuses shell commands and scripts (cmd, PowerShell, .bat…), links that aren't http/https, typing into the Run box, apps with command-line arguments, and the panic chord. If the trigger is already used, you get the normal conflict message.

Free daily limit

Text mode works out of the box with Keyware's free AI. To keep it free for everyone there's a daily limit of 20 requests per PC, reset every day. If you reach it, Keyware says “Daily AI limit reached, try tomorrow or add your own free key” and offers a button to add one. Manual mode is never limited.

Use your own AI key

With your own free key, Text mode talks to the AI directly and Keyware's daily limit doesn't apply. Your key is stored encrypted on your PC with Windows (DPAPI), never in plain text, and it's only ever sent to the AI provider you got it from.

  1. Recommended: Google Gemini (free). In Keyware, click the gear (top right) to open Settings, scroll to AI key (optional) and turn on Use my own free key.
  2. Press Get a free key. It opens aistudio.google.com/apikey. Sign in with your Google account and click Create API key.
  3. Copy the key. A Gemini key starts with AIza.
  4. Paste it into Paste your key, press Save, then Test. You should see that the key works.
  5. Alternative: Groq (free). Create a key at console.groq.com/keys. It starts with gsk_. Paste, Save and Test it the same way.

Keyware detects which kind of key you pasted and tells you straight away if it doesn't look like a Gemini or Groq key. To go back to Keyware's free AI, turn Use my own free key off.

Privacy. Text mode sends the sentence you typed and a short summary of your setup (your leader key, profile names, the apps they apply to, and triggers you already use) so the AI can draft the binding. That goes through Keyware's server, or straight to Google or Groq if you use your own key. Your keystrokes are not uploaded. See the privacy statement.

06

Conflict prevention

One trigger can only do one thing. If you try to save a binding whose trigger is already used in the same profile, Keyware stops and tells you which binding has it:

F2 is already used by “Open YouTube” (Tap F2). One trigger can only do one thing. Replace it, or pick another trigger.

Replace

Press Replace to swap the old binding for the new one, or choose a different key. Keyware also catches subtler overlaps: a Tap, a Hold and a Double-tap on the same key count as the same key. The exception is Holds of different lengths, which work as tiers (for example hold P 800 ms for one thing and 2 s for another). Using the same trigger in an app profile and in Global is allowed: the app's version wins while that app is in front.

Deleting a binding (with Undo)

Every binding card has a trash icon. Click it and the binding is removed right away, no confirmation dialog. A small bar appears at the bottom of the window for 5 seconds:

Ctrl + Win + Shift + ROpen YouTube
Deleted Open YouTube.Undo

Press Undo and the binding comes back exactly where it was. To keep a binding but stop it firing, flip its switch off instead.

New in 1.4.1

Advanced scripting

Settings has Advanced scripting. It is off until you turn it on. Manual and Text mode do not show a script box while it is off, and a normal binding does not need a script.

When it is on, a binding can carry a short script. Leave the box empty and the action above runs as usual. do runs that action. A script can also branch on the app in front, the profile, the setup, or the modifiers that were held, then type, click, or open a page or app.

A script cannot open a shell, run a command, or wait more than 2 seconds in total. The keyboard hook never runs it. Pause and Ctrl Alt Shift Esc stop it between steps and release any key it pressed. Dry run logs the script and does not run it.

07

Pause, panic stop and dry run

CtrlAltF12

Pause

Stops all remaps instantly and lets every key through. The tray icon shows a pause mark. Press the same keys to turn it back on. A small note says “Keyware off” or “Keyware on”. You can change these keys in Settings.

CtrlAltShiftEsc

Panic stop

The emergency brake. Drops Keyware's keyboard hook, releases any held keys, cancels a running macro and stops auto-click. Keyware then pauses until you turn it back on from the window or tray.

Settings → Dry run

Dry run

Test without consequences: Keyware writes what would fire to the log, and every key passes through as normal.

New in 1.3.7

Turning Keyware on and off

Press Ctrl Alt F12 at any time to turn Keyware off. A small note pops up saying Keyware off. While it's off, every key and mouse button works normally and no bindings run.

Press the same keys again to turn it back on. You'll see Keyware on.

Use other keys: open Settings (the gear), click the On/off shortcut box, press your new keys, and click Save. Use at least one of Ctrl, Alt, Shift or Win plus one other key. It can't be the panic stop keys.

Panic stop is different: it fully lets go of the keyboard, and you turn Keyware back on from the window or tray.

New in 1.3.7

Switching setups

A profile can have up to nine numbered setups. Each setup has its own bindings, so the same key can do one thing in one setup and something else in another. Bindings that aren't in a setup always work.

Example, Minecraft: in your Minecraft profile, make 1 Elytra and 2 Spear. Put your flying keys in setup 1 and your fighting keys in setup 2.

  1. Add setups: pick the profile, type 1 Elytra, 2 Spear in the Setups box under its name, and click Save.
  2. Put a binding in a setup: in the Quick Binder, type the number in the Setup # box next to the label. Leave it empty for “always on”.
  3. Switch: while the game is in front, hold the number key (top row, 1 to 9) for 8 seconds. A small note says, for example, Setup 2: Spear.
  • A quick tap or short hold still types the number like normal. Keyware never blocks the key, it only counts how long you hold it.
  • Holding a number that isn't a setup does nothing.
  • Keyware remembers the active setup for each profile, even after a restart.
  • Change the 8 seconds in Settings › Setup hold (s). Set it to 0 to turn setup switching off.

Per-app

Per-app shortcut rules

A new binding works in every window. You only add a per-app rule when one app should treat the key differently:

  • Keyware handles it: run your action and hide the key from that app.
  • App: let the app keep its own shortcut. Keyware does nothing there.
  • Both: run your action and also pass the key to the app.

In Manual mode the line under Per-app rules says the binding works in every window until you add an app. In Text mode, say it: “Ctrl+K opens Notion, but let Cursor keep Ctrl+K”.

Fixed in 1.3.8. App and Both used to let the key go down and then swallow the key-up, so the app could see a stuck key. The press and the release now both reach the app. App still skips Keyware's action. Both still runs the action and passes the key. A short hold does not type the key a second time.

FAQ

Is Keyware free?

Yes, completely: no trial, no paid tier, no ads and no account.

Is Keyware open source?

Yes, under the MIT license. The app, its tests and this website's code are on GitHub, so anyone can read exactly what Keyware does, build it themselves or suggest a change.

Does Keyware work on a Mac?

No. There is no Mac download, on Apple Silicon or Intel. Keyware remaps keys with a Windows keyboard and mouse hook (WH_KEYBOARD_LL, WH_MOUSE_LL, and SendInput). On a Mac the window can edit a config, and the header says the keyboard hook is only installed on Windows. Turning Keyware on does not remap keys. A working Mac version would be a different input system, not another build of Keyware.exe.

Is it safe to use?

Keyware runs as a normal app without administrator rights. It only acts on keys you've bound; every other key passes straight to Windows. It never injects keys into elevated (admin) windows, and the panic stop Ctrl Alt Shift Esc switches it all off instantly.

Open URL only accepts web links, Open app can't pass command-line arguments, and Text mode refuses shell commands and scripts.

What about my privacy? Is anything tracked?

No tracking, no analytics, no ads. Keyware doesn't log what you type: the log only notes which bindings fired. Your bindings and settings live on your PC in %APPDATA%\Keyware\config.json.

The key engine does not upload what you type. Text mode sends the sentence you type into the Text box, plus a short summary of your existing triggers and profile names so the AI avoids clashes. Your keystrokes are not uploaded. A Play action looks up the name you entered.

If you send an idea, feedback or a bug report from Settings, Keyware sends your message, the email you enter, the app version and a random install ID. The server stores the message, the email, the version and a short salted hash of the install ID, so we can reply if we need more information. It does not send your bindings, settings or keystrokes, and it is never used for marketing.

Read the full privacy statement for exactly what is sent, where it is stored and for how long.

Why does Windows warn me when I open it?

Keyware isn't code-signed, so SmartScreen warns about an app it does not recognise. Click More info → Run anyway. The warning is about the missing signature, not about a problem found in the file. The SHA-256 listed with the download is how you check you received the file this site publishes.

Does it work in games?

Yes, in most games. Put game shortcuts in the Gaming profile and add your game's .exe. Games running as administrator won't receive Keyware's keys. Some online games with strict anti-cheat ban macros and auto-clickers, so check the rules first.

Will my normal typing be affected?

No. Unbound keys aren't touched. A Hold or multi-tap key still types normally on a short press, and modifier shortcuts like Ctrl C keep working.

Can I back up or move my bindings?

Yes. Copy %APPDATA%\Keyware\config.json to the other PC (same folder) and choose Reload config from the tray.

How do I uninstall it?

There's no installer. To remove Keyware:

  1. In Settings, turn off Start Keyware with Windows. It is on by default. Turning it off deletes the Keyware startup entry for your Windows account. If you skip this, Windows still tries to open Keyware when you sign in.
  2. Right-click the tray icon and choose Quit.
  3. Delete Keyware.exe. If you also downloaded the ARM64 build, delete Keyware-arm64.exe too.
  4. Optional: delete the %APPDATA%\Keyware folder. That removes your settings, the install ID and a saved AI key. They stay on the PC until you do.

Troubleshooting

Nothing happens when I press my shortcut

  • Is Keyware on? The dot next to the title should be green, and the tray icon shouldn't be dimmed.
  • Is it paused? Press Ctrl Alt F12.
  • Is the binding's switch on, and is it in the profile that's active now? Use Edit live profile to check.
  • Is Dry run on in Settings? Turn it off.
  • Check the log at the bottom of the window. It explains why a key didn't fire.

It doesn't work in one particular app or game

  • If that program runs as administrator, Windows blocks normal apps from sending it keys. Run it normally, or accept that remaps pass through there.
  • Make sure its .exe name is in the right profile (Task Manager → Details shows the name).

“Keyware is already running”

  • Only one copy runs at a time. Look for the icon in the tray (click the ^ by the clock) and choose Show Keyware.

Text mode shows an error

  • “That doesn't look like a key binding”: describe a key and what it should do, e.g. “F9 opens YouTube”.
  • “Too many bindings at once”: ask for 8 or fewer.
  • “Daily AI limit reached, try tomorrow or add your own free key”: you've used today's free requests. Wait until tomorrow or add your own free key.
  • “AI busy”: the free AI is overloaded for a moment. Try again in a minute, or add your own key.
  • Your own key is refused: open Settings, check the key (Gemini starts with AIza, Groq with gsk_) and press Test.
  • A timeout or network error: check your internet connection, then try again, or use Manual mode.

A key feels stuck

  • Press the panic stop Ctrl Alt Shift Esc. It releases everything Keyware pressed. Keyware also releases keys automatically after sleep or the lock screen.

The Copilot key still opens Copilot

  • Check the binding is on, Keyware isn't paused, and Dry run is off.
  • If Windows' Customize Copilot key setting or your laptop maker's app is set to something else, it runs before Keyware. Set it back to the default.

My settings look wrong after editing config.json

  • If the file can't be read, Keyware keeps your previous settings and says so in the log. A corrupt file is saved as config.json.bak and replaced with defaults.

Windows Defender or antivirus flagged it

  • SmartScreen, unrecognized app. A blue “Windows protected your PC” window that says Microsoft Defender SmartScreen prevented an unrecognized app from starting is because Keyware isn't code-signed. That is not a malware detection. If you downloaded Keyware from this site, click More info, then Run anyway. A new copy can ask again. Compare the SHA-256 on the download with Get-FileHash .\Keyware.exe -Algorithm SHA256 or Get-FileHash .\Keyware-arm64.exe -Algorithm SHA256 if you want to confirm the file.
  • Malware or threat detection. If Microsoft Defender or another antivirus names a virus, trojan, or other threat, do not run the file and do not add an exclusion. Delete it and download Keyware again only from this site.
