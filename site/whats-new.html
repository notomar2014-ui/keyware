What's new in Keyware

Remap any key or mouse button, build macros and hotkeys, and set per-app shortcuts, just by describing them in plain English.

6 November 2026

Version 1.3.8

  • Per-app rules no longer stick a key. With App or Both, Keyware 1.3.7 let the key go down and then swallowed the key-up, so the app in front could see a stuck key. The press and the release now both reach that app. App still skips Keyware's action. Both still runs the action and passes the key. A short hold does not type the key a second time. Per-app shortcut rules

The home page offers two Windows builds of this version: 64-bit Keyware.exe (20.2 MB) and native ARM64 Keyware-arm64.exe (15.5 MB). On ARM64 Windows the 64-bit file runs under emulation. There is no Mac download.

Choose 64-bit (x64) or ARM64 · Release v1.3.8 on GitHub

5 November 2026

Version 1.3.7

  • Setups inside a profile. Up to 9 numbered setups per profile, each with its own keys, for example Minecraft with 1 Elytra and 2 Spear. Hold the number key for 8 seconds to switch; a quick tap still types the number. How to use setups
  • On/off shortcut. Ctrl Alt F12 turns Keyware off and on, with a small note each time. Change it in Settings. More
  • Per-app shortcut rules. Let an app keep its own shortcut, run Keyware's action, or both, and set it just by describing it in Text mode. More

2 November 2026

Version 1.3.6

  • Any key or mouse button. Use middle click, back/forward, the wheel and tilt, modifier + left/right click, or any Windows key code as a trigger. More
  • Donate button. A way to support Keyware, right in the app.
