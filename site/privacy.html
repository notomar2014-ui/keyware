Privacy statement

Your keys stay yours

Keyware has no accounts, no ads, no analytics and no tracking cookies. This page explains exactly what the Keyware app and this website (keyware-app.vercel.app) send, what is stored, where, and for how long.

01

In short

  • No accounts, no sign-up, no ads, no analytics and no tracking cookies, in the app or on this website.
  • The key engine works offline. Your bindings and settings stay on your PC in %APPDATA%\Keyware.
  • Only Text mode sends anything for AI: the sentence you type plus a short summary of your existing setup, so the AI doesn't suggest a clashing key.
  • A random install ID and your IP address are used, only in salted, hashed form, to apply fair daily limits and to count downloads.
  • Feedback you choose to send (message, email, app version) is used only to reply to you. It is never shared or sold.
  • We never sell, rent or share personal information for marketing.
  • Keyware is open source (MIT). You can check every point on this page in the code on GitHub.

02

The Keyware app

Keyware listens to your keyboard on your PC so it can run the bindings you create. Keys you haven't bound pass straight to Windows. Keystrokes are never recorded, uploaded or sent anywhere. The local log only notes which binding fired, not what you typed.

Your bindings, profiles and settings are saved in %APPDATA%\Keyware\config.json on your PC. If you add your own AI key, it is saved there too, encrypted with Windows' built-in data protection (DPAPI) so only your Windows account can read it.

The app only goes online in these cases:

  • Text mode, when you press the button to draft a binding (see below).
  • Feedback, when you press Send in Settings → Suggestions & feedback.
  • Actions you create, when you trigger them. For example, Open URL opens the page in your browser, and a “play” action looks up the song or video name you entered on YouTube, Spotify, DuckDuckGo or Bing to find it. Those sites receive the request directly, under their own privacy policies.

The app has no telemetry, no crash reporting and no automatic update checks.

03

Text mode (AI)

When you describe a binding in plain words, Keyware sends:

  • the sentence you typed (up to 500 characters);
  • a short context summary: your leader key, the profile you're editing, your profile names with the app names (.exe) they apply to, and the triggers you already use, so the AI avoids clashes;
  • the app version and the random install ID (see rate limits).

By default this goes to Keyware's server (keyware-app.vercel.app/api/bind), which forwards the sentence and context, but not the install ID or your IP address, to an AI provider: Google Gemini or Groq. Keyware's server does not store or log your sentence or the AI's reply. Its logs only note the result, the model used, the time taken and the sentence length.

If you use your own AI key, the app sends the sentence and context directly from your PC to Google or Groq, and Keyware's server is not involved at all.

The AI providers process the text under their own terms. Free AI plans may let the provider keep or review inputs to improve their services, so don't type passwords or other private details into Text mode. See Google's Gemini API terms and Groq's privacy policy.

04

Rate limits & download counts

Install ID. The first time you use Text mode or send feedback, Keyware creates a random ID (a UUID) and saves it in your config file. It is not linked to your name, email, Windows account or hardware.

Daily AI limit. To keep the free AI fair (20 requests per install and 60 per IP address a day), the server combines the install ID and your IP address with a secret salt and keeps only a shortened SHA-256 hash of each, never the raw values. These counters are held in the server's memory for the current day only and are discarded after about a day or when the server restarts.

Download counts. When you download Keyware from this site, the server creates a salted hash of your IP address and browser name for 10 minutes, so a double click counts once. The saved download record contains only the date and a random ID, with no IP address, hash or browser details. Bots and link previews are not counted.

Similar salted hashes limit how much feedback one install or network can send per day.

05

Feedback

Sending an idea, feedback or a bug report from Settings → Suggestions & feedback is optional. It sends:

  • the type (Idea, Feedback or Bug) and your message;
  • the email address you enter;
  • the app version.

The server also stores a short salted hash of the install ID with it, so repeated reports from one install can be grouped. Nothing else is attached: no logs, settings, bindings or screenshots.

We use feedback only to understand and fix problems and to reply to you if we need more information. It is never shared, sold or used for marketing, and you won't be added to any mailing list.

06

This website & cookies

This website uses no analytics, no ads, no trackers and no third-party scripts, fonts or embeds. It sets no cookies for visitors and doesn't use local storage.

The only cookie on the site is a sign-in cookie for the private admin dashboard (/admin). It is set only after the admin password is entered, is limited to the /admin pages, can't be read by scripts and expires after 8 hours. Visitors never receive it.

Like any website, the hosting provider receives standard request data, such as your IP address and browser name, to deliver pages and protect against abuse (see Other services).

07

Storage & retention

Keyware's server and storage are hosted on Vercel (functions in the United States, Vercel Blob for files). Only the admin can see stored data.

DataWhereKept for
Your bindings, settings, install ID, own AI key (encrypted)Your PC, %APPDATA%\KeywareUntil you delete them
Text mode sentence and AI replyNot stored by Keyware (only passed to the AI provider)Not kept
Rate-limit counters (salted hashes)Server memoryUp to about 26 hours
Download de-duplication (salted hash)Server memory10 minutes
Download records (date + random ID)Vercel Blob (no personal data)Until deleted
Feedback (message, email, app version, hashed install ID)Vercel Blob (private)Until deleted
Usage totals (AI requests, active installs, per-model counts)Server memoryUntil a server restart

Feedback is not deleted automatically: it is kept until the admin deletes it. If you want your feedback removed, ask through the feedback form and it will be deleted.

08

Other services

  • Vercel hosts the website, the Text mode server and storage. Vercel privacy policy.
  • Google (Gemini API) and Groq process Text mode requests. Google privacy policy · Groq privacy policy.
  • Ko-fi handles payments if you choose to support Keyware. Keyware only receives the amount, currency, whether it's one-time or monthly, and the date. It does not receive your name, email or message.

None of these receive any information from Keyware for advertising.

09

Your choices

  • Use Manual mode only: Keyware then never contacts Keyware's server or any AI provider.
  • Use your own AI key to send Text mode requests straight to Google or Groq.
  • Delete %APPDATA%\Keyware to remove everything Keyware stored on your PC, including the install ID.
  • Ask for your feedback to be deleted at any time.

10

Contact & changes

For any privacy question or deletion request, use the feedback form in the app: Settings (gear icon) → Suggestions & feedback. Include the email address we should reply to.

If these practices change, this page will be updated and the date at the top will change.
